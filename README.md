# DevOps Capstone Project

## Project: devops-capstone-project

This project develops a customer accounts microservice for an e-commerce application.

The service provides REST API functionality to create, read, update, delete, and list customer accounts.

The project demonstrates Agile planning, Test-Driven Development, Continuous Integration, Docker containerization, Kubernetes deployment, and Continuous Delivery using DevOps practices.
